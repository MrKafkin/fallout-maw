# Fallout-MaW

Free automated system for **Foundry VTT 14**, with Russian and English presets, libraries and journals.

## Installation

In Foundry Setup, open **Game Systems → Install System** and paste this Manifest URL:

```text
https://github.com/MrKafkin/fallout-maw/releases/latest/download/system.json
```

[Latest full release](https://github.com/MrKafkin/fallout-maw/releases/latest) · [Project page](https://boosty.to/mrkok)

For manual installation, download the attached full ZIP and extract its contents into `Data/systems/fallout-maw/`, so that `system.json` is directly inside that folder. This repository hosts release manifests and complete installation packages.
